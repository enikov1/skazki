## Обязательные условия запуска

1. Постоянная БД и постоянное хранилище загружаемых изображений/MP3. Бесплатный preview с `/tmp` не предназначен для настоящих пользовательских данных.
2. Реальный SMTP: проверить доставку регистрации и восстановления; `MAIL_MAILER=log` не доставляет письма.
3. Queue worker и scheduler; контроль ошибок и резервных копий. Проверить восстановление БД вместе с медиа.
4. Домен, TLS, проверенный список доверенных прокси. Не включать TRUSTED_PROXIES=* на обычном публичном сервере.
5. Удалить временные ADMIN_PASSWORD/demo credentials из runtime, отключить SEED_DEMO_CONTENT, проверить права на реальные материалы.
6. Выполнить `php artisan site:check`. Положительный результат не заменяет проверку восстановления backup и реальных доставок SMTP.
7. Повторить полный browser QA для guest/user/editor/moderator/admin на 360/390/768/1024/1440 px, клавиатуру, печать и реальные Safari/Firefox/Chrome.
8. Открывать SITE_INDEXABLE только после наполнения и прохождения release checklist.
